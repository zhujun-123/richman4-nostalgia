## 已知还原差异

以下来自上游 2026-10-06 的 [状态说明](STATUS.md)，尚未在本 fork 独立复核：

- 游戏时间、胜利条件设置与投降尚未实现，相关界面灰色。
- 原版 AVI 过场未实现；上游手中的素材是占位视频，不能推断其他版本的素材也如此。
- 动画开关只影响小游戏。
- 圣诞节第二组地图送卡规则未移植。
- 魔法屋目标仍由玩家选择，原版为随机目标。
- 托管状态不能直接保存核心状态，上游在交出控制前自动保存。
- 仍有只写入日志的提示，字体、动画时序和声音混音也可能与原版有差异。
- 上游基于 v3.11 光盘版，Steam 版素材未完成逐一比对。

此外，本机没有检测到原版细明体，启动器会使用已有的系统中文字体。它可以显示中文，但不能据此声称字形一比一。

## 一比一验收方式

1. 使用用户自己的原版素材，记录资源包哈希、版本及字体来源。
2. 在相同地图、存档、日期、玩家和 640×480 比例下，逐页比较标题、新游戏、棋盘、地产、银行、股市、卡片道具、存读档和小游戏。
3. 覆盖默认、按下、禁用、取消和返回等状态，并检查台词、动画顺序、音效和背景音乐。
4. 完成买地、升级、付租、银行、股票、卡片道具、住院、监狱、月底结算及存读档的实际对局。
5. 将差异列为可复现问题；只有完成这些验证，才调整对应的还原结论。

当前结论：已经建立独立的原版素材驱动移植仓库；尚不具备“100% 一比一完成”的证据。
